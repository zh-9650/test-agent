# Triage Labels

工程 Skills 使用五种规范状态。GitHub 中的标签保持同名，避免重复词汇。

| 规范状态 | GitHub 标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者判断 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 信息完整，可由 AFK Agent 处理 |
| `ready-for-human` | `ready-for-human` | 需要人类执行或裁决 |
| `wontfix` | `wontfix` | 当前不会处理 |

Wayfinder 另使用：

- `wayfinder:map`
- `wayfinder:research`
- `wayfinder:prototype`
- `wayfinder:grilling`
- `wayfinder:task`

修改标签名称时，必须同步更新本文件和 `docs/agents/issue-tracker.md`。
