## 3. Phase 2.0A 做了什么

### Sprint 1: Goal Reminder（`execution_graph.py`）

- `decide_node` 顶部注入任务持久化守卫块（用例ID/标题/描述/当前步骤/成功标准）
- 每个 HumanMessage 最顶部显示，LLM 每步看到目标，防止长上下文漂移

### Sprint 2: ActionResult（`interfaces.py`, `tools.py`）

- 新增 `ActionResult` pydantic 模型：action / target / success / error / before_url / after_url / page_changed / url_changed
- 14 个工具全部返回 `ActionResult.model_dump()` dict
- `execute_node` 将 `ActionResult` 传给 `assert_node`
- `_make_action_result()` 统一构造器，自动计算 DOM fingerprint 变化

### Sprint 3: Wait-for-Stable（`tools.py`）

- `_wait_for_stable(page, timeout=5000, poll_interval=250)`: networkidle 2s + DOM 指纹轮询 + 500ms buffer
- 不新增 LangGraph 节点，直接在 14 个工具内部调用
- DOM 指纹三维度: `elCount_htmlLen_textLen`

### Sprint 4: DOM 语义增强（`page_semantic.py`, `prompts.py`）

- `page_semantic.py`: 所有元素提取函数加 semantic properties（visible/enabled/readonly/required/checked/selected/role + 加 input_type/label/placeholder/name）
- `prompts.py` `_format_page_info`: 紧凑索引格式 `[N] tag "text" (prop1, prop2, ...)`
- `_resolve_element`: 支持 `[N]` 格式解析（靠 `_normalize_target`）

### Sprint 5: Failure Memory（`interfaces.py`, `execution_graph.py`, `prompts.py`）

- `TestState` 增加 `recent_failures: list[dict]`（default_factory=list）
- `execute_node`: 工具失败追加 {action, target, error, url}，最多 3 条
- `observe_node`: 注入 `page_info["_failure_warnings"]`
- `_format_page_info`: 在元素列表**最顶部**显示告警（"⚠️ 警戒区"）

### Sprint 6: Loop Detection（`interfaces.py`, `execution_graph.py`）

- `TestState` 增加 `action_history: list[dict]` + `need_replan: bool`
- `record_node`: 每次执行后追加 action 到 history (name/url/fingerprint, 最多 6 条)
- `record_node`: AAA 检测（连续 3 次相同 action）+ ABAB 检测（4 步交替）
- `decide_node`: `need_replan=True` 时注入 `[SYSTEM INTERRUPT]` 微重规划提示

### 实验性设计: assert 条件边的量化评估

B3.1 实现后需跑 50 case 验证:
- **预期收益**: 中间步骤跳过 assert_node → 每步 ~2-5ms LangGraph 调度节省
- **风险**: assertion 准确率可能下降
- **决策**: `avg_step_duration` 下降 > 10ms 则永久启用；准确率下降 > 5% 则回滚

### CDP 迁移推迟

原计划 Phase 2.0B 的 CDP 迁移 → **Phase 2.0C**，触发条件: 100 case locator 失败率 > 30%。
