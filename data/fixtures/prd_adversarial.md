# 缺陷 PRD - 测试 fact_extractor 鲁棒性

> 故意写得**模糊 / 矛盾 / 不可定位**，用于验证：
> 1. fact_extractor 能否在 source 字段正确标记 inferred
> 2. assertion_deriver 能否在低质量输入下推导出断言
> 3. pipeline 能否识别 paraphrase 后的规则

## 业务背景

某审批系统（具体系统名未知）。用户能"做某些操作"。

## 规则

1. 大金额可能需要审批。  ← 模糊、缺数字
2. 金额阈值是 5k 还是 5000 视情况而定。  ← 自我矛盾
3. 详见 code（无 quote 可引）  ← 无可追溯源
4. 系统对金额超过五千元整的单据，必须经过部门负责人的审阅。  ← 同 #2 数字写法的 paraphrase
5. 提交的申请，最终会被处理。  ← 信息量≈0
6. 用户 18 岁以下不能注册。  ← 与审批系统无关
7. 申请人死亡则流程终止。  ← 不可能场景
8. 如果已审批通过，就不能再审批了。  ← 同义反复
9. 经理可以批准金额为一万元的单子。  ← 重复 #4
10. 超过 10000 要更高一级的审批。  ← 缺主语
