# AI 对话平台 (AI Talk) - 产品需求文档

> 测试目标: http://192.168.31.155/login?redirect=/ai-talk/index
> 测试账号: test_c / 123456

## 1. 产品概述

AI 对话平台是面向企业用户的智能对话工作站。已登录用户可以创建多个"对话会话 (Conversation)"，每个会话由一个"AI Agent"驱动，支持多轮对话、上下文记忆、会话分享与历史检索。

## 2. 角色定义

| 角色 | 权限 |
|------|------|
| 普通用户 (test_c) | 创建/删除自己的会话、发送消息、查看自己的历史、修改个人资料 |
| 管理员 | 上述全部 + 用户管理 + Agent 配置 + 全局统计 |

## 3. 业务规则

1. 任何已登录用户都可以创建新的对话会话。
2. 每个会话必须绑定一个 AI Agent（系统内置或用户自建），会话创建后不允许更换 Agent。
3. 单个用户的会话数量上限为 100 个，超过后必须先删除旧会话才能创建新会话。
4. 消息发送支持纯文本（最长 8000 字符）与图片（最大 5MB，jpg/png/webp）。
5. 每次 AI 回复的最大等待时间为 30 秒，超时系统返回"AI 响应超时，请重试"。
6. 用户可以"点赞"或"点踩"AI 的每一条回复，点踩后必须填写原因（最少 10 字符）。
7. 用户可以将会话"分享"给其他用户，被分享者获得"只读"权限，不能发送新消息。
8. 会话列表按"最后更新时间"倒序排列，每页显示 20 条。
9. 删除会话为软删除，30 天内可在"回收站"中恢复；30 天后系统自动物理删除。
10. 用户修改密码时必须输入旧密码，新密码长度至少 8 位且包含数字与字母。
11. 单次登录失败连续 5 次后账号锁定 10 分钟，期间任何登录尝试均提示"账号已锁定"。
12. 用户登出时，浏览器端的 localStorage 中的 token 必须被立即清除。

## 4. 状态机

### 4.1 会话状态流转

```
[新建] -> [进行中] -> [已结束]
                  \-> [已分享]
```

- 新建：会话刚创建，尚未发送任何消息
- 进行中：会话中存在至少一条消息，且未被标记结束
- 已结束：用户主动点击"结束对话"
- 已分享：会话被分享给其他用户（与"进行中"可共存）

### 4.2 消息状态流转

```
[发送中] -> [已发送] -> [AI 思考中] -> [已回复]
                          \-> [回复失败]
```

## 5. 接口约定

```
POST   /api/auth/login              登录
POST   /api/auth/logout             登出
GET    /api/conversations           列出当前用户的会话
POST   /api/conversations           创建新会话
GET    /api/conversations/{id}      查看会话详情
DELETE /api/conversations/{id}      删除会话（软删）
POST   /api/conversations/{id}/messages  发送消息
GET    /api/conversations/{id}/messages  获取消息历史
POST   /api/conversations/{id}/share     分享会话
POST   /api/messages/{id}/feedback       提交反馈（点赞/点踩）
GET    /api/agents                  列出可用 Agent
```

## 6. 关键页面

- `/login` — 登录页
- `/ai-talk/index` — 会话列表 + 入口
- `/ai-talk/c/{id}` — 单个会话的对话页
- `/ai-talk/profile` — 个人资料 + 密码修改
- `/admin/users` — 管理员用户管理（仅管理员）
