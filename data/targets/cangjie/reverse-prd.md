# 仓颉知道反向 PRD

## 1. 产品定位

仓颉知道是一个多租户智能体与知识库关联管理控制台。核心价值是管理外部 AI 智能体平台接入、维护 FastGPT 知识库数据集、配置智能体与知识库的一对一绑定关系，并提供系统级技能插件管理。

## 2. 用户与权限

主要用户为管理员。管理员登录后进入控制台，可访问:

- 智能体广场
- 知识库管理
- 技能管理

所有业务接口均需要登录后携带 Bearer Token 和固定 `clientid`。未登录访问业务接口应返回 401。

## 3. 登录模块

### 目标

用户通过账号密码登录系统。登录成功后进入控制台并展示当前用户名、API 网关健康状态和业务导航。

### 关键规则

- 用户名必填。
- 密码必填。
- 支持密码显隐切换。
- 支持记住密码，将凭据写入 localStorage。
- 登录成功后写入 `cj_access_token`、`cj_is_logged_in`、`cj_logged_user`。
- Token 失效时应清理登录态并回到登录页。

### 已发现规格校准

- 历史 PRD 和登录页代码中的一键填值密码为 `cangjie*2026`。
- 当前本地启动文档和网关实测可用密码为 `admin123`。
- 因此一键填值体验当前不是可靠登录路径，应作为缺陷或规格不一致风险验证。

## 4. 智能体广场

### 目标

管理员维护外部智能体平台接入配置，支持搜索、新增、编辑、删除和免登跳转。

### 关键数据

- 智能体名称: 必填，同租户未删除数据内唯一。
- 业务描述: 选填。
- 网关地址: 必填，必须以 `http://` 或 `https://` 开头。
- 接入 Token: 选填，留空时后端自动生成。
- 关联知识库: 选填，但必须遵守一对一绑定。

### 关键规则

- 列表默认按创建时间倒序展示。
- 列表中 Token 只展示脱敏值。
- 已绑定知识库的智能体禁止删除，需要先解绑。
- 免登跳转接口返回拼接 Token 的跳转 URL，前端打开新窗口后通过 postMessage 继续传递当前登录 Token。

## 5. 知识库管理

### 目标

管理员维护 FastGPT 知识库数据集，并上传文本或文件集合，为智能体提供专属 RAG 语料。

### 关键数据

- 知识库名称: 必填。
- 描述: 选填。
- 文档名称: 必填，文本语料保存时未带 `.md` 后缀应自动补齐。
- 文档内容: 必填，Markdown 文本。
- 文件上传: 支持 pdf、docx、md、txt、html、csv。

### 关键规则

- 知识库和智能体是一对一绑定。
- 已绑定智能体的知识库禁止删除，需要先解绑。
- 列表展示知识库名称、描述、集合数量、创建时间和绑定状态。
- 语料上传后应刷新知识库列表或集合数量。

## 6. 技能管理

### 目标

管理员维护系统级技能插件，支持分页搜索、脚手架创建、ZIP 上传、状态切换、逻辑删除、导出、详情、文件树和文件编辑。

### 关键数据

- 技能名称: 1 到 50 字符。
- 版本号: 默认 `1.0.0`，支持语义化版本。
- 作者: 默认“本站开发者”。
- `SKILL.md`: 核心文件，不允许重复创建或删除。
- 文件路径: 禁止连续斜杠和空目录名。

### 关键规则

- 脚手架创建应自动生成 `SKILL.md` 和 `index.js`。
- 更新 `SKILL.md` 时应同步技能元数据。
- 更新元数据时应回写 `SKILL.md` Frontmatter。
- 删除技能和文件均为逻辑删除。

## 7. 本轮测试目标

本轮先做高价值小范围验收，不追求全量覆盖:

- 登录页加载和基础交互。
- 管理员使用真实凭据登录。
- 一键填值密码失效风险。
- 登录后导航和三大业务模块加载。
- 智能体、知识库、技能列表接口是否可用。
- 新增智能体、知识库、技能脚手架等写操作至少验证一个正向路径和一个负向/约束路径。
- 观察当前 `test_agent` 在真实登录态、业务写操作、证据记录方面暴露的能力缺口。
