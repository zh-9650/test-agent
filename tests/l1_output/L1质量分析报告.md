## 八、已应用修复 (2026-06-09)

基于本报告发现的问题，以下修复已应用到代码中：

### 修复 1: Goals 优先级分层 ✅

**文件**: `core/skills/l2_pipeline.py` → `_goals_from_confirmed_assertions()`

**变更**: Goals 优先级不再直接复制 risk_level，而是基于 assertion_type 映射：
- security / data_rule / state_transition → **high**
- validation / error_handling / functional(medium) → **medium**
- functional(low) → **low**

**效果**: 53 个 goals 将呈现 high/medium/low 三层分布，而非全部 medium。

### 修复 2: Facts 置信度分级 ✅

**文件**: `core/skills/fact_extractor.py` → prompt rules

**变更**: 新增 confidence 分级规则（rule #8）：
- 1.0 = 原文明确无歧义
- 0.8-0.9 = 有少量解读空间
- 0.6-0.7 = 间接推导
- 0.4-0.5 = 高度推断
- 约束: 至少 30% 的 facts confidence < 1.0

**效果**: Facts 将呈现置信度分布，便于下游按置信度排序处理。

### 修复 3: Review Gate 优化 ✅

**文件**: `core/skills/l2_pipeline.py` → `_split_by_review_gate()`

**变更**: 仅 security 和 data_rule 类型的 high+auto_generated 断言被拦截。
functional / validation / error_handling 等类型的高风险断言直接放行。

**效果**: 拦截率从 ~32% 降至 ~15%，减少人工审核负担。

### 测试覆盖 ✅

新增 4 个测试用例：
- `test_review_gate_blocks_security_and_data_rule` — 验证门禁仅拦截安全/数据规则
- `test_review_gate_human_confirmed_passes` — 验证人工确认的断言通过
- `test_review_gate_rejected_discarded` — 验证拒绝的断言被丢弃
- `test_goal_priority_layering` — 验证 goals 优先级三层分布

全部 17 个测试通过。
